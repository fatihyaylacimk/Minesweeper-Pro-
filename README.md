# 💣 Minesweeper Pro

A modern cyberpunk-themed Minesweeper game built with pure HTML, CSS, and JavaScript.

## 🎮 Features

- ✅ Easy, Medium, Hard difficulty modes
- ✅ Custom map generator
- ✅ First-click safe system
- ✅ Animated cell reveal effects
- ✅ Flag and question mark system
- ✅ Hint system
- ✅ Combo system
- ✅ Sound effects using Web Audio API
- ✅ Multiple themes
- ✅ Local leaderboard
- ✅ Responsive design
- ✅ Mobile support
- ✅ Win/Lose animations
- ✅ Countdown mode support
- ✅ Dynamic background effects

## 🛠 Technologies

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Web Audio API
- Local Storage

## 🚀 Installation

1. Clone the repository

```bash
git clone https://github.com/yourusername/minesweeper-pro.git
```

2. Open the project folder

```bash
cd minesweeper-pro
```

3. Run the game

Open:

```bash
index.html
```

in your browser.

No additional installation is required.

## 🎯 How To Play

### Left Click
Reveal a cell.

### Right Click
Place a flag.

### Double Click
Auto reveal surrounding cells.

### Long Press (Mobile)
Place a flag.

### Hint Button
Reveal a safe cell.

## 🏆 Scoring System

The score is calculated based on:

- Difficulty level
- Completion time
- Revealed cells
- Hints used

Faster completion and fewer hints result in higher scores.
